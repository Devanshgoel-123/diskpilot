macOS says “System Data.” That's all it says.

On a developer's Mac, that grey block is build output, package caches, Docker's disk image, simulator runtimes and editor data for projects you deleted months ago. None of it is labeled, so none of it feels safe to touch.

DiskPilot names every part of it, and tells you which parts you'd never miss.

          Example.

          Your storage. Your decision.

          DiskPilot never calls something safe because it's large or old. Every cleanup goes through the same steps, and the one in the middle is you.

          1. Scan Read-only. Nothing changes.
          2. Suggest A tier, the reason and the risk for each item.
          3. You review The exact paths and space, confirmed by you.
          4. Check again Each path is re-checked just before it moves.
          5. Trash Recoverable until you empty the Trash.
          6. History Every action and its result is recorded.
          Likely safe

          Data the tool rebuilds on its own: package caches, build output, app caches, logs.

          Review first

          Probably unused, but something may depend on it: data for deleted projects, old versions, stale backups.

          Keep

          Important, or not understood well enough: conversation history, sign-in data, settings, Docker volumes, your own files.

          • System folders and key home folders are refused outright.
          • Docker volumes are never removed, and every Docker command is shown first.
          • A reviewed plan is single-use and expires after ten minutes.
          • Empty Trash removes only the exact items you reviewed.

          Nothing leaves your Mac unless you ask.

          No account, no telemetry. Scanning, analysis and cleanup all run on this Mac.

          Stays on this Mac

          • Every scan, size and path
          • Cleanup history and saved results
          • Private folders such as Mail and Messages, which DiskPilot only ever sizes
          • Your files' contents, which DiskPilot never reads

          Only when you ask the assistant

          The optional assistant answers questions like “What can I safely clean up?” with your own Anthropic API key, kept in the macOS Keychain. It's off until you turn it on.

          • Your question and the storage data it needs: names, paths and sizes
          • Sent straight from your Mac to Anthropic's API
          • Read-only: it can't delete, move or run anything

          Up and running in a minute.

          One download for Apple silicon and Intel Macs, macOS 11 or later.

          DiskPilot isn't notarized by Apple yet. The first time you open it, macOS says Apple cannot check it for malicious software. Step 3 below is how you allow it, once. After that it opens like any other app.

          1. Download

            Get DiskPilot.dmg. One file runs on every Mac.

          2. Move to Applications

            Open the disk image and drag DiskPilot into the Applications folder.

          3. Allow it once

            Open DiskPilot and choose OK when macOS warns you. Then open System Settings, Privacy & Security, scroll down and click Open Anyway next to DiskPilot. On macOS 14 and earlier you can instead Control-click the app and choose Open.

          4. Scan

            Click Scan. DiskPilot reads your home folder and changes nothing until you review and confirm a cleanup.

          Check the download

          Each release lists its SHA-256 checksum and a signed record of how it was built. With the GitHub CLI: 

          shasum -a 256 DiskPilot.dmg
gh attestation verify DiskPilot.dmg -R Devanshgoel-123/diskpilot

          Prefer to build it yourself? The source and build steps are on GitHub, along with every release.

          Questions people ask first

          Can DiskPilot delete something important?

          Nothing is removed without a preview you confirm. Items go to the Trash, system and key home folders are refused outright, and conversation history, sign-in data, settings and Docker volumes are never recommended.

          Does it need Full Disk Access?

          No. macOS asks once before protected folders such as Desktop, Documents and Downloads are read, and folders such as Mail, Messages and the Photos library are skipped and reported. Grant it if you want those measured too: DiskPilot reads sizes only, keeps them on your Mac, and the assistant sees each of those folders only as a total.

          Does the app send any data?

          No. There is no account and no telemetry. The optional assistant is the only feature that uses the network, only when you ask it something, and it never sends file contents.

          Why does macOS warn me when I first open it?

          Apple shows that warning for apps that aren't notarized through a paid Apple developer account. DiskPilot is open source, so you can read every line, check how each release was built, or build it yourself. Signed and notarized releases are planned.

          Is there a Windows version?

          Not yet. It's planned after signed macOS releases. The engine is Rust and the shell is Tauri, which already builds for Windows; the work is teaching DiskPilot how Windows stores things, with the same rules: NTFS-aware sizes, OneDrive placeholders left alone, the Recycle Bin first, Docker's WSL disk explained, and system folders off limits. Watch the GitHub repository to hear when a preview is ready.
