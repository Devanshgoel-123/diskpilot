Features

Everything a developer's disk accumulates, explained

Generic cleaners see folders. DiskPilot sees the project, the tool and the version that created them, and whether any of it is still used.

Every folder explained

Each folder gets one of eleven categories, the rule that matched, its confidence and a sentence on what it is. You see why ~/Library/Developer is 30 GB, not just that it is.

Application data Cache Build artifacts Developer tools Docker storage Logs

Finds data for deleted projects

Editor workspace storage, Xcode DerivedData and agent sessions whose project folder no longer exists, confirmed against the disk.

Docker without the guesswork

Images, containers and build cache from Docker's own numbers. Every action shows the exact command first. Volumes are never touched.

AI agent and editor cleanup

Old Claude Code versions, Cursor update downloads, stale database backups, MCP logs and Copilot leftovers. Conversation history is never recommended.

Trash first, with a history

Items move to the Trash, so you can put them back. Every cleanup is logged with each item's outcome.

An optional assistant that cannot delete

Turn it on with your own Anthropic key and ask "what can I safely remove?" It reads DiskPilot's findings and highlights recommendations for you to review. It has no tool that changes your disk, and file contents are never sent.

How it works

Five stages, one safety gate

Every cleanup moves through the same steps in the same order. The last step checks every path again just before it acts.

  1. Scan

    Measures real on-disk size in parallel. Stays on one volume, never follows symlinks, counts hard links once.

  2. Classify

    Matches each folder to a rule: DerivedData, node_modules, Cargo target, editor caches and more.

  3. Recommend

    Regenerable data becomes a suggestion with a tier, the reason, the risk and an alternative command.

  4. Preview

    A single-use plan of exactly what will move and how much space it frees. It expires in ten minutes.

  5. Execute

    Re-checks each path, refuses protected folders, moves items to the Trash and records the result.

Likely safe

Regenerable data the tool rebuilds on its own: package caches, build output, app caches, logs.

Review first

Probably unused, but something may depend on it: data for deleted projects, old versions, stale backups.

Keep

Important or not understood well enough: conversation history, sign-in, settings, Docker volumes, your files.

Install

Up and running in a minute

DiskPilot is not yet notarized by Apple, so macOS asks you to confirm it the first time you open it. After that it opens like any other app.

  1. Download

    Get DiskPilot.dmg. One file runs on Apple silicon and Intel Macs.

  2. Move to Applications

    Open the disk image and drag DiskPilot into the Applications folder.

  3. Allow it once

    Open DiskPilot. When macOS says it cannot verify the developer, choose Done, then go to System Settings, Privacy & Security, and click Open Anyway next to DiskPilot.

  4. Scan

    Click Scan. DiskPilot reads your home folder and changes nothing until you review and confirm a cleanup.

Prefer to build it yourself? The source and build steps are on GitHub. Updates are published there as new releases.

On the roadmap

Coming to Windows

The engine is Rust and the shell is Tauri, which already builds for Windows. The work is teaching DiskPilot how Windows stores things, with the same safety rules.

  • NTFS-aware scanning

    Real allocated size, hard links counted once, junctions and symlinks never followed, long paths supported.

  • Cloud files left alone

    OneDrive placeholders are measured without downloading them, and never counted as local data.

  • Recycle Bin first

    The same preview-then-confirm flow, moving items to the Recycle Bin instead of deleting them.

  • Docker and WSL disks

    Docker's WSL 2 disk file does not shrink after pruning. DiskPilot will explain why and show the compaction steps.

  • Windows developer data

    npm, pnpm and NuGet caches, Visual Studio and Gradle data, editors and agents under AppData.

  • System folders protected

    Windows, Program Files and the component store are off limits. Windows Update cleanup is left to Windows' own tools.

FAQ

Questions people ask first

Can DiskPilot delete something important?

Nothing is removed without a preview you confirm. Items go to the Trash, system and key home folders are refused outright, and conversation history, sign-in data, settings and Docker volumes are never recommended.

Does it need Full Disk Access?

No. macOS asks once before protected folders such as Desktop, Documents and Downloads are read, and folders such as Mail, Messages and the Photos library are skipped and reported. Grant it if you want those measured too: DiskPilot reads sizes only, keeps them on your Mac, and the assistant sees each of those folders only as a total.

Does the app send any data?

No. There is no account and no telemetry. The optional assistant is the only feature that uses the network, only when you ask it something, and it never sends file contents.

Why does macOS warn me when I first open it?

Apple shows that warning for apps that are not notarized through a paid Apple developer account. DiskPilot is open source, so you can read every line or build it yourself. Signed and notarized releases are planned.

Is it really free?

Yes. DiskPilot is open source under the MIT license, with no paid tier.

When is Windows support coming?

It is planned after signed macOS releases. Watch the GitHub repository to hear when a preview is ready.
