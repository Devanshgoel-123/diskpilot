DiskPilot 0.4.0 finds duplicate files and local AI models, measures the private folders macOS protects once you allow it, and puts everything that frees space in one place.

## Download

**[DiskPilot.dmg](https://github.com/Devanshgoel-123/diskpilot/releases/download/v0.4.0/DiskPilot.dmg)**. One universal app for Apple silicon and Intel Macs, macOS 11 or later.

To update, quit DiskPilot, then drag the new version into Applications and replace the old one. Your history, settings and saved results are kept. If macOS says it cannot verify the developer, open **System Settings > Privacy & Security** and select **Open Anyway** once.

## What's new

### Duplicates

- **Duplicates** finds files with identical contents: same size first, then a SHA-256 of the contents. Files under 1 MB, hidden folders, `~/Library`, app bundles, dependency folders and package caches are skipped.
- You choose which copy stays. One copy of every set always stays, and each copy is compared byte for byte with it again just before it is moved to the Trash.
- Hard links are counted once, and APFS clones are marked "No space to free", because removing a clone gives back little or nothing.

### Private folders and Full Disk Access

- Mail, Messages, Photos, iCloud Drive and Safari are often among the largest folders on a Mac, and macOS only lets an app measure them with Full Disk Access. The Overview now says which private folders were not measured and opens the right page in System Settings.
- Sizes are measured on this Mac and nothing leaves it. If you use the assistant, it sees each private folder only as a single total, never the names of the files inside.

### For developers

- **Local AI models**: Ollama and LM Studio model stores are measured on the Developer Tools page, and Ollama layers no model uses any more, or left over from interrupted downloads, are suggested for the Trash.
- **Credentials in AI transcripts**: Developer Tools can check Claude Code, Codex CLI and Gemini CLI transcripts on this Mac for API keys, tokens and private keys that were pasted or printed into a session. Values are always shown masked, and nothing is sent anywhere.

### Simpler layout

- **Storage** now has two tabs: **Folders** to browse by size, and **Largest items** (previously the Large Files page).
- The sidebar is grouped into finding space (Storage, Duplicates, Applications, Developer Tools, Docker) and getting it back (Cleanup, History).
- The Overview shows how much is waiting in the Trash, with **Empty Trash** next to it. Cleanup moves items to the Trash so they stay recoverable, and the space comes back once the Trash is emptied.
- A **menu bar item** shows the space available on your startup disk and opens Cleanup, Duplicates or Empty Trash. Closing the window keeps it running; **Quit DiskPilot** ends the app.

### Removed

- Starting and stopping Docker containers. DiskPilot's Docker page is for seeing and reclaiming space; use Docker Desktop to run containers.

Everything still runs locally, with no account and no telemetry.

This release is built from the tagged source by the Release workflow on GitHub Actions.
