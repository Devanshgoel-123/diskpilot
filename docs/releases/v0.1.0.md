The first release of DiskPilot: free, open-source storage intelligence for macOS.

## Download

**[DiskPilot.dmg](https://github.com/Devanshgoel-123/diskpilot/releases/download/v0.1.0/DiskPilot.dmg)**. One universal app for Apple silicon and Intel Macs, macOS 11 or later.

## Install

1. Open `DiskPilot.dmg` and drag DiskPilot into Applications.
2. Open DiskPilot. This build is not yet notarized by Apple, so macOS reports that it cannot verify the developer. Choose **Done**, then open **System Settings > Privacy & Security** and select **Open Anyway** next to DiskPilot. On macOS 14 and earlier you can instead Control-click the app and choose **Open**.
3. Click **Scan**. DiskPilot reads your home folder and changes nothing until you review and confirm a cleanup.

## What is included

- **Overview** of the whole disk by category, with likely recoverable space marked and the items most worth reviewing.
- **Storage**, **Large Files** and **Applications** to see what uses space, including data left behind by removed apps.
- **Cleanup** with explained recommendations in three tiers (Likely safe, Review first, Keep), a preview of exact paths, and Trash-first removal.
- **Developer Tools** analysis for Cursor, VS Code, Claude Code, Codex, GitHub Copilot, Node.js, Xcode, Rust and Python.
- **Docker** usage with previewed actions. Volumes are never removed.
- **Cleanup History** of every action, and an optional read-only assistant that uses your own Anthropic API key.

Everything runs locally. There is no account and no telemetry.

This release is built from the tagged source by the Release workflow on GitHub Actions.
