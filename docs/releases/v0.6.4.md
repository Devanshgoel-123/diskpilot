DiskPilot 0.6.4 recognises five more developer and media caches, all from a first-time contributor.

## Download

**[DiskPilot.dmg](https://github.com/Devanshgoel-123/diskpilot/releases/download/v0.6.4/DiskPilot.dmg)**. One universal app for Apple silicon and Intel Macs, macOS 11 or later. Signed with a Developer ID and notarized by Apple.

Coming from 0.6.0 or later: DiskPilot shows a banner when the update is ready; install it with one click.

## What's changed

### New locations

DiskPilot now recognises these folders, explains what is in them, and offers them in Cleanup:

- **Deno**: downloaded modules and compiled TypeScript in `~/Library/Caches/deno`. Deno fetches them again when a script runs.
- **Swift Package Manager**: downloaded package repositories in `~/Library/Caches/org.swift.swiftpm`. Shown with Xcode & Apple tools.
- **Puppeteer**: Chrome builds downloaded for testing in `~/.cache/puppeteer`. Other folders in `~/.cache` are still listed one tool at a time.
- **NuGet**: downloaded .NET packages in `~/.nuget/packages`. `dotnet restore` fetches them again.
- **Adobe media cache**: conformed audio, peak files and the media cache database that Premiere Pro, After Effects and other Adobe apps keep in `~/Library/Application Support/Adobe/Common`. Quit Adobe apps before clearing it; they rebuild the cache when a project opens.

### Smaller changes

- The Credentials in AI transcripts panel no longer says that agents keep every conversation.
