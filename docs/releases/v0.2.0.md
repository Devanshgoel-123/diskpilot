DiskPilot 0.2.0 remembers your last scan and points out older versions and other things you no longer need.

## Download

**[DiskPilot.dmg](https://github.com/Devanshgoel-123/diskpilot/releases/download/v0.2.0/DiskPilot.dmg)**. One universal app for Apple silicon and Intel Macs, macOS 11 or later.

To update, quit DiskPilot, then drag the new version into Applications and replace the old one. Your history and settings are kept. If macOS says it cannot verify the developer, open **System Settings > Privacy & Security** and select **Open Anyway** once.

## What's new

### Saved results

- The last scan is saved on your Mac, so DiskPilot opens straight to your results. A new scan runs only when you click **Scan**.
- Results older than a day show their age and a **Rescan** button.
- When you review a cleanup, every item is measured again on disk, and anything already gone is left out, so the total is current.
- Only folder names and sizes are saved, never file contents. **Settings > Saved results > Clear results** removes them.

### Older versions and leftovers

Cleanup now marks items with a tag and the evidence behind it, and can show one kind at a time:

- **Older version**: a newer version is installed next to it. Covers JetBrains IDEs and Android Studio, Xcode device support, Android build tools and NDK, Gradle, Node.js (nvm), Python (pyenv), Ruby (rbenv), Homebrew, and Claude Code and Cursor command-line versions.
- **Leftover**: the app, extension or project it belonged to is no longer there.
- **Installer**: a disk image or package in Downloads for an app that is already installed.
- **Duplicate**: a "name (1)" download that is identical, byte for byte, to the original.

The default or in-use version is never marked. Python, Ruby and Homebrew versions come with a command to run yourself instead of a remove button, because other environments can depend on them. Findings under 1 MB are listed in Developer Tools but not suggested in Cleanup.

### Smaller changes

- The developer-tools analysis runs automatically after each scan, so its findings appear in Cleanup without opening Developer Tools first.
- Cleanup details no longer show "0 files" for items found by the analyzers.

Everything still runs locally, with no account and no telemetry.

This release is built from the tagged source by the Release workflow on GitHub Actions.
