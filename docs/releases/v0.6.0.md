DiskPilot 0.6.0 keeps itself up to date, groups your videos, images and installers by type, shows previews before you remove anything, keeps count of the space you have cleared, and recognises browser, chat app and Go storage.

## Download

**[DiskPilot.dmg](https://github.com/Devanshgoel-123/diskpilot/releases/download/v0.6.0/DiskPilot.dmg)**. One universal app for Apple silicon and Intel Macs, macOS 11 or later. Signed with a Developer ID and notarized by Apple.

Coming from 0.5.1 or earlier: quit DiskPilot, then drag the new version into Applications and replace the old one. This is the last time you need to do that by hand. Your history, settings and saved results are kept.

## What's changed

### Updates inside the app

- DiskPilot checks for a new version once a day and shows a banner when one is ready. Install it with one click; DiskPilot restarts on the new version.
- Every update is signed, and DiskPilot checks the signature before installing anything.
- After an update, "What's new" shows what changed. Turn the daily check off, or check now, in Settings > Updates.

### Files by type

- A new By type tab in Storage groups your own videos, images, audio, archives, installers and documents, with the total for each.
- Filter by folder (Downloads, Desktop and so on), by name, or by files you have not changed in 6 months or a year.
- Select several files, review them, and move them to the Trash in one go. These are your files, so DiskPilot never calls them safe to delete: you decide.
- Files inside apps, ~/Library, hidden folders, Photos and Final Cut libraries, and project build output are left out.

### Space cleared and streaks

- History shows how much space DiskPilot has cleared on your Mac, how many cleanups that took, and your weekly streak: weeks in a row with at least one cleanup. The Overview shows the same in one line.
- Deleted and trashed space both count; emptying the Trash is not counted twice. These numbers stay on your Mac and are not sent anywhere.

### See before you remove

- Duplicates shows a thumbnail of every copy. Press Space for a large preview, like Quick Look, and the arrow keys to move between files. The same preview works in Files by type.
- Previews are made only for files DiskPilot listed, never for anything else on your Mac.

### Docker

- Stop a running container from the Containers table with one click.
- Remove a running container in one step: DiskPilot stops it, then removes it.
- When you remove a container, DiskPilot lists the volumes it uses. Tick the ones you also want deleted and type the container's name to confirm. Volumes another container uses are kept.
- Delete a volume that no container uses, after typing its name to confirm. Volumes in use cannot be deleted.
- A container started with `--rm` is deleted by Docker as soon as it stops. DiskPilot says so, and will not stop one whose anonymous volumes would be deleted with it.
- DiskPilot runs exactly the commands you reviewed: if Docker changed in the meantime, it asks you to review again.

### Recognises more

- Browser caches for Chrome, Brave, Edge, Arc, Chromium and Vivaldi in every profile, and the web caches of apps such as Slack, Discord and Notion. Quit the browser or app first. Data that sites keep for offline use is listed separately, to review first.
- Telegram's media cache, with how to clear it inside Telegram, and WhatsApp media, which is shown but never suggested for removal.
- Playwright browsers, and tool versions installed with asdf or mise.
- Go: the build cache can be cleared, and the module cache is shown with Go's own command to clear it, since Go makes it read-only. A Go analyzer also finds caches you moved with `go env -w`. Contributed by [@chinmayajha](https://github.com/chinmayajha), DiskPilot's first outside contributor.

### Safer

- Deleting a folder now stops before anything is removed if any part of it could not be deleted: read-only folders, locked files, items with access rules, or a read-only folder around it. It used to remove part of the folder and leave the rest.
- Empty Trash now removes folders that tools such as Go and DotSlash make read-only. It used to fail on them with "Permission denied" every time.
- Moving items to the Trash works even if you did not let DiskPilot control Finder. It used to fail with "Not authorized to send Apple events". Finder may not offer Put Back for those items, but you can still drag them out of the Trash.
- Duplicates and Files by type no longer offer files inside Cardboard, ScreenFlow, Aperture, iPhoto and Capture One projects, the Music, TV and Photo Booth libraries, or virtual machines, which their apps need.
- If Go's build cache is set to a folder other tools also use, DiskPilot no longer offers to remove that folder.
