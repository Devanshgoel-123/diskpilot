DiskPilot 0.6.6 shows what your AI coding agents may do on your Mac, and finds the key and credential files you've lost track of.

## Download

**[DiskPilot.dmg](https://github.com/Devanshgoel-123/diskpilot/releases/download/v0.6.6/DiskPilot.dmg)**. One universal app for Apple silicon and Intel Macs, macOS 11 or later. Signed with a Developer ID and notarized by Apple. This release was built and notarized on the maintainer's Mac rather than on GitHub Actions, so it has no GitHub build attestation; check it with the SHA-256 checksum below and `spctl --assess --type open --context context:primary-signature -v DiskPilot.dmg`.

Coming from 0.6.0 or later: DiskPilot shows a banner when the update is ready; install it with one click.

## What's changed

### AI Agents

A new page for Claude Code, Codex, Cursor and Antigravity. Only the agents installed on your Mac are shown.

- **Permissions:** what each agent may do without asking, in plain words. Settings that let it act on its own, such as running any shell command or working outside the sandbox, are listed first. Commands you approved once with "Yes, don't ask again" are listed separately and can be cleared together.
- **MCP servers:** what each agent is connected to. Disconnect a server you no longer use; DiskPilot keeps its settings so you can reconnect it exactly as it was. Keys and arguments are never shown.
- **Plugins and skills:** turn a Claude Code plugin off or on, and see skills you haven't used in 30 days. Your own inactive skills can be reviewed and moved to the Trash; skills that come with a plugin go with the plugin.
- **Can free:** caches, logs, old versions and everything else each agent stores. The Claude app, GitHub Copilot and other agent tools are here too, along with the check for keys pasted into AI transcripts. They moved from Developer Tools.
- **Keys in transcripts:** remove the keys a transcript holds with one click. Each key is replaced with "[removed by DiskPilot]" and the rest of the conversation stays, so you can still resume it. Revoke the key with its provider as well.

Every change asks first, edits one settings file and saves a copy of it beforehand.

### Keys & secrets

Private keys, certificates, `.env` files and cloud credentials found by your scan, with what makes each one risky: readable by other accounts, sitting in Downloads or on the Desktop, in a git project without a `.gitignore` entry, copied in several places, or years old.

- **Make private** so only your account can read a key, show it in Finder, or move it to the Trash.
- **Label** a key with what it's for (AWS, GitHub, Apple…) and find it later by searching.
- DiskPilot reads the first 512 bytes of a file to tell a key from a certificate. To spot copies, it reads key files of up to 1 MB on your Mac and compares their checksums. It never shows or sends what's inside. The list and your labels are saved encrypted on your Mac, with the key in your Keychain. There is no export.

### Storage

The Folders view now shows what fills the folder you're in. One bar splits it by item, with the biggest ones named underneath with their size and share. The part your cleanup recommendations cover is hatched. Click a name to open that folder.

- **Recommended here:** how much the recommendations inside the folder add up to, and one button to review them.
- **Cleanup column:** click an item's tier or its "inside" amount to review just those recommendations.
- Each row's bar shows its share of the folder, so smaller items no longer look empty next to one big folder. Unclassified items show a dash instead of "Unknown".

### Smaller changes

- **AI Agents:** agents and other AI tools are listed side by side in one column that stays in view. Pick the Claude app, Copilot or another agent CLI to see what it stores.
- **Developer Tools:** Node.js, Go, Rust and Python cards show their logos, and VS Code shows its app icon.
- **Scans:** a scan's results appear as soon as it finishes. The key files it found are saved afterwards, and checked side by side instead of one at a time.
- **Sidebar:** Cleanup sits next to Overview; Storage, Duplicates and Applications are under Find space; AI Agents, Keys & secrets, Developer Tools and Docker under For developers.
- **History:** pages through up to 500 scans and cleanups instead of showing the last 50.
- **Signup:** you'll get one email with a link to confirm your address. Only confirmed addresses are ever emailed again, and unconfirmed ones are deleted after 30 days.
- **Light and dark:** switch from the button at the top right of every page.
- **Overview:** after a cleanup, the storage bar and its numbers move to the new values instead of jumping.
- ⌘9 opens AI Agents.
